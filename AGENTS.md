# DeepCluster setup requests

If you are running in DeepSeek Harness and the user asks you to install DeepCluster from this repository, follow the [service installation guide](docs/setup.md) from the revision you cloned. It covers building the plugin, starting the service, and checking a worker.

If the user asks you to connect the coding tool you are running in, follow the [agent connection guide](docs/agent-skills.md). Locate the existing DSH installation and install the skill for your current tool.
